# Universal Calculator

Run `python main.py` for the command-line app or `python main.py --gui` for the graphical app.

## Physics

Physics is organized in the normal introductory textbook progression: measurement and vectors, kinematics, forces, energy, momentum, rotation, gravitation/fluids, waves, thermodynamics, electricity, magnetism, optics, and modern physics. Select a chapter and then an equation. Each equation first shows its symbolic form, variable meanings/SI units, and a choice to calculate or rearrange it for any listed variable. Angles are entered in radians.

The existing Algebra calculator remains available for custom equations or equations outside the current physics reference.
